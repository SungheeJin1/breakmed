# breakmed — 목각 인형 부수기

약을 먹어야만 벨 수 있는 짚단 인형(大자 모양 베기 연습용 목각 인형) 게임 — 휴대폰 홈 화면에 설치하는 웹앱.

- 매일 **오전 10시**에 1·2번째 인형(칼슘제·홍삼), **밤 10시**에 3번째 인형(여드름약) 도착 → `📦 목각 인형 받기`
- 순서대로 부수기: **1. 칼슘제 → 2. 홍삼 → 3. 여드름약**
- 인형을 누르면 “칼슘제를 먹었습니까?” 창이 뜨고 버튼은 **`먹었다.`** 하나뿐
- 누르면 칼날이 대각선으로 **싹둑!** → 윗부분이 베인 면을 따라 미끄러져 떨어짐 + 짚 부스러기 + 진동/효과음
- 새벽 4시 전까지는 전날로 인정 / 연속 성공 일수 표시
- 오프라인에서도 열림 (서비스 워커 캐시)

## 알림
| 방법 | 오프라인 | 설명 |
|---|---|---|
| `reminders.ics` (앱 안 “📅 캘린더에 알림 추가”) | ✅ | 휴대폰 캘린더에 매일 10:00 / 22:00 반복 알림 등록. 가장 확실함 |
| 앱 알림 | ⚠️ | 앱이 살아 있는 동안만 동작 (휴대폰이 앱을 종료하면 안 옴) |

## 휴대폰에 올리기 (GitHub Pages)
1. 저장소 **Settings → Pages → Source: GitHub Actions**
2. `main`에 푸시하면 자동 배포 → `https://<계정>.github.io/breakmed/`
3. 휴대폰에서 열고 **홈 화면에 추가**

## 바꾸기 쉬운 설정 (`app.js` 맨 위)
`BREAK_HOUR`, `DOLLS[].arrive`(인형별 도착 시각), `DAY_START_HOUR`, `SEQUENTIAL`, `DOLLS`(약 이름·질문·색)
알림 시간을 바꾸면 `reminders.ics`의 시간도 함께 바꾸세요.
